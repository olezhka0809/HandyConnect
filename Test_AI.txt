Pregătire (obligatoriu înainte de orice test)
 + Pornește serverul AI — în terminal: cd server && node index.js → trebuie să apară Server running on port 5000
 + Pornește clientul — alt terminal: cd client && npm run dev
 + Loghează-te cu un cont de client pentru testele 1–2, cu handyman pentru 3–5
TEST 1 — PostTask: Analiză foto → completare automată formular
Rută: /post-task · Cont: Client

 + Mergi la „Postează Task" (butonul din dashboard client)
 + La Step 1, în secțiunea „Adaugă poze", încarcă 1–3 fotografii ale unei probleme (ex: robinet, priză, perete crăpat)
 + Apare butonul „Analizează cu AI ✨" după upload?
 + Apasă butonul → apare spinner „Analizez imaginile…"?
 + După ~5–10 secunde se completează automat: Titlu, Descriere, Categorie, Cuvinte cheie?
 + Apare bannerul verde „Formularul a fost completat automat"?
 + Câmpurile completate sunt editabile (poți modifica manual)?
TEST 2 — PostTask: Estimare buget AI
Rută: /post-task → Step 2 · Cont: Client (continuă din testul anterior sau creează un task cu titlu + descriere)

 Completează Step 1 cu titlu + descriere (manual sau prin AI)
 + Ajunge la Step 2 (click „Continuă")
 + În secțiunea Buget apare butonul „Estimează bugetul cu AI"?
 + Apasă butonul → apare spinner „Calculez prețul…"?
 + Apare panelul cu 3 valori: Minim / Recomandat / Maxim în RON?
 + Apare eticheta de precizie (Precizie ridicată / medie / generală)?
 + Apare textul de explicație (reasoning)?
 + Butonul „Aplică valoarea recomandată" populează câmpul de buget cu suma recomandată?

 Apasă butonul → apare spinner „Generez lista…"?
 Apare lista cu Unelte (checkbox-uri)?

 Apare Timp estimat (ex: 2.5h) în panelul albastru de sus?
 Poți bifa/debifa itemii din liste?
 Închide și redeschide modalul → lista este salvată (nu dispare)?
